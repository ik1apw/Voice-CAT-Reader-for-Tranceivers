Ciao a tutti OM,
condivito un piccolo progetto che ho realizzato:
👉 **Voice CAT Reader**
È un software per PC che permette la lettura vocale della frequenza e modo operativodi RTX  utilizzando OmniRig, senza hardware aggiuntivo e senza modificare il settaggio esistente.
Il programma annuncia  in tempo reale o su richiesta da tastiera.

Requisito: OmniRig già installato e configurato.

Hotkey: CTRL + ALT + R
Funzione: legge frequenza e modo tramite OmniRig.

Hotkey: CTRL + ALT + L
Funzione: Cambia la Lingua

Hi everyone,
I'm sharing a little project I've created:
👉 **Voice CAT Reader**
It's a PC software that allows you to read the RTX frequency and operating mode by voice using OmniRig, without additional hardware or changing existing settings.
The program announces in real time or on keyboard input.
🎯 Designed primarily to improve accessibility (blind radio amateurs), but useful for everyone.

Requirement: OmniRig already installed and configured.

Hotkey: CTRL + ALT + R
Function: Reads frequency and mode via OmniRig.

Hotkey: CTRL + ALT + L
Function: Change Language
